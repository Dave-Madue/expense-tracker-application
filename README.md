# Expense Tracker Web App

A responsive web application that allows users to track daily expenses and visualize their financial activity.  
Built with React.js, this app provides a simple interface to add, view, and manage transactions in real-time.


## Features
- Add and delete expenses or income entries  
- Calculate and display total balance dynamically  
- Visual transaction history  
- Responsive and mobile-friendly interface  


## Tech Stack
- React.js
- Context API
- CSS3
- REST API Integration
